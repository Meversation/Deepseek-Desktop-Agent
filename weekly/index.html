01

桌面 UI 重构

侧栏按工作区与会话分层，常用入口集中到左侧；会话可以续接，不再每次重开新对话。

  • 侧栏采用 Trae 式结构，工作区 / 会话 / 任务 / 设置分区
  • 会话续接，切换页面不打断上下文
  • 常用操作收进侧栏入口，减少主界面层级

02

网页改为按需窗口

DeepSeek 网页不再常驻后台，需要时再唤起；会话页面同步瘦身，信息密度更低。

  • 网页窗口按需唤起，用完即可释放
  • 会话页面减负，输入与回复更聚焦
  • 窗口生命周期跟随主程序，避免残留进程

03

可控的 Agent

随时踩刹车，停下来的任务不会丢。

紧急停止

一键中断正在执行的操作，避免命令继续跑偏。

消息队列

停止后可以继续输入，任务按顺序补跑，不丢上下文。

版本发布 v1.5.1

本轮改动已合并到主分支并发布，文档与许可证同步更新。

  • 桌面端：UI 重构落地，会话续接可用
  • 网页：改为按需窗口，会话页瘦身
  • Agent：停止与队列行为稳定
  • 发布：README、设计文档、许可证同步
