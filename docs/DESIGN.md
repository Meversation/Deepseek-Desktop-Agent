# Deepseek-Desktop-Agent · 设计规范（DESIGN）

本规范为**强制约束**：此后所有界面改动都必须先满足本文件，再谈功能。

## 一、全局约束

1. **配色**：全局 UI 主题统一为「深色 + 蓝色」体系，亮色主题仅作可选；所有控件（含自绘控件、列表、单选/复选、滚动条、弹窗）必须使用同一套主题令牌（`ThemePalette`），不得出现系统原生浅色残留。
2. **输出框只读**：所有输出/回复框点击后不出现闪烁光标、不可编辑，但允许选中复制、滚动。
3. **输入/输出框滚动条**：全局禁用原生滚动条，统一使用自绘细滚动条（半透明轨道、按内容比例变长的滑块）。
4. **不必要时不出现滚动条**：内容不需要大量滚动即可完整查看的区域（顶栏、表单页、卡片、单行标签等）不得出现横向或纵向滚动条；宽度不足时用省略号或换行，而不是加滚动条。
5. **简洁不杂乱**：功能不得随意堆放；位置与分布要符合直觉。功能过多时，**有取舍地把一部分收进「设置」**，主界面只保留高频操作。

## 二、主页（针对 Trae 风格）

```
┌──────────────┬──────────────────────────────────────────────┐
│ 技能入口      │                Build With DeepSeek           │
│ （优先加载）   │                                              │
├──────────────┤   ┌────────────────────────────────────────┐  │
│              │   │  输入框（多行，自绘滚动条）              │  │
│  会话列表     │   └────────────────────────────────────────┘  │
│ （按文件夹分组）│   [工作目录] [权限/审批策略] [发送]           │
│              │                                              │
│              │   DeepSeek 页面（默认折叠，点按展开）           │
└──────────────┴──────────────────────────────────────────────┘
```

- **左侧栏**
  - 顶部：Skill 相关功能入口，**优先加载**（会话级技能注入）。
  - 主体：会话列表，按工作目录分组，可回溯、可切换、可筛选。
  - 底部：设置入口（低频功能全部归到这里）。
- **主区域**
  - 顶部大标题 `Build With DeepSeek`，作为主页视觉锚点。
  - 中部为输入框 + 发送；输入框支持 Ctrl+V 粘贴图片作为附件。
  - 输入框下方只保留少量高频项：工作目录、权限/审批（沙箱、高风险确认、签字审核、完全绕开 → 具体策略在设置里配置）。
  - DeepSeek 网页默认**折叠**，需要时展开（对应 TODO ⑦：默认内嵌改为「打开 DS 窗口」入口）。
- **会话语义**：同一个文件夹下，「Build With DeepSeek」的每一轮对话记为一个会话；选择旧会话继续时，左侧加载历史会话内容，输入框置于底部，DS 页面保持折叠。
- **Markdown 渲染**：内置预览器（参考 Trae），回复以 Markdown 渲染展示，不使用网页截图代替可复制文本。

## 三、实现约定

- 主题令牌集中在 `Theme.cs`，新增颜色必须同时补齐 Light/Dark 两套。
- 自绘控件放在 `MainForm.Widgets.cs`：单选 `ThemedRadio`、按钮 `AccentButton`、滚动条 `LineScrollBar`、数字输入 `NumberField`、标签栏 `SegmentedTabs`。
- 只读文本控件必须使用 `NoCaretTextBox` / `NoCaretRichTextBox`，滚动用 `LineScrollBar`。
- 任何新页面先自查：是否引入原生滚动条、是否在暗色下出现黑字、是否有控件被裁切。
- 文案统一使用中文，按钮动词优先（选择工作目录 / 发送 / 展开 DS 页面）。
