01

环境要求

  • Windows 10 / 11
  • Microsoft Edge（系统自带）或 Google Chrome
  • 需要 .NET 10 SDK 仅用于自行构建；发布版为自包含单文件，无需安装运行时

02

起源 —— 为了省钱

先说一下网络上的项目：

  • DeepSeek Harness 等正经的 Agent 功能更强，但都需要 API-Key、都要花钱买 token。
  • 网页反代 等同类方案通过反代白嫖 token，功能强大，但封号概率很大。
  • 本项目采用 CDP 自动化操控网页，封号概率相对更小（但不为 0，详见页尾声明）。

再看这个项目的由来：

  • DeepSeek 网页无法直接编辑电脑文件，最多生成代码再复制粘贴，不能真正「操控」电脑。
  • 思路很直接：让它生成 PowerShell，执行，再把结果扔回去。
  • 于是有了这个项目：DeepSeek 网页版可以编辑文件、看屏幕、控制键鼠、编辑 Excel/Word。

03

快速使用

  • 从 Releases 下载任一版本：Deepseek-Desktop-Agent-self-contained.exe（自包含，无需运行时）或 Deepseek-Desktop-Agent-framework-dependent.exe（仅程序本体，需 .NET 10 Desktop Runtime）。
  • 右键选择以管理员身份运行。
  • 点击 选择工作目录，选择一个目录。
  • 程序会自动启动 Edge/Chrome 并打开 DeepSeek，请先自行登录。
  • 点击 开始 / 继续，等待 AI 读取系统提示词。
  • 之后在 Deepseek Desktop Agent 的输入框发消息，不要用网页版发消息。网页窗口仅用于查看。

04

实现原理 —— 自动化脚本

  • 本项目不是反代，没有第三方中转，也没有逆向 DeepSeek 网页。
  • 核心是 CDP 自动化模拟用户操作，与反代一样违反了 DeepSeek 用户协议。
连接 Chrome/Edge 调试端口（默认 9222），
通过 CDP WebSocket 在 DeepSeek 页面里执行 JavaScript，
模拟输入、上传文件、点击发送，
并轮询判断助手回复是否完成、返回助手回复内容。

05

本次更新 —— C# 重写

界面与运行时由 C# / WinForms 重写，工具协议与提示词保持一致，原有逻辑不变。

编码修复

提示词与脚本统一 UTF-8，读取中文文件不再乱码。

窗口内嵌

DeepSeek 窗口不可单独关闭，随主程序退出，也可一键还原为独立窗口。

后台执行

PowerShell 在后台运行，不弹黑框，指令与输出实时显示在内置选项卡。

双输入框

主程序与内嵌浏览器输入框均可正常输入，焦点自动切换。

会话选择

可选择历史会话继续，而不是每次误开新对话。

主题与快捷键

昼夜切换不再抽搐，兼容 Ctrl+A / C / X / V / Z / Y。
